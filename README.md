**pf2e-uk** — неофіційний український переклад системи **Pathfinder 2e** для **Foundry Virtual Tabletop**.

Модуль містить переклад інтерфейсу PF2e, компендіумів, ігрових термінів, описів та частини підтримуваних модулів. Переклад інтерфейсу самого Foundry VTT надає окремий рекомендований модуль [FoundryVTT Ukrainian](https://github.com/GMonlineua/foundryvtt-uk).

> Модуль активно розвивається та редагується. Частина текстів може бути неперекладеною, неточною або потребувати вичитки.

## Встановлення

1. Відкрийте **Configuration and Setup** у Foundry VTT.
2. Перейдіть у **Add-on Modules** та натисніть **Install Module**.
3. Вставте адресу в поле **Manifest URL**:

   ```txt
   https://github.com/NikolasTS/pf2e-uk/releases/latest/download/module.json
   ```

4. Натисніть **Install** і дочекайтеся завершення встановлення залежностей.
5. Увімкніть модуль у світі через **Manage Modules**.
6. Встановіть Українську мову як мову Foundry. (**Configure Settings** -> **Core** -> **Language Preference** -> **Ukrainian / Українська**)
